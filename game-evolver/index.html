Game-Evolver: better games through better orchestration

Xucong Wang · Xinghan Chen · Yundong Zhang · Weidong Zhang

AI Platform Dept (AIPD), Tencent

Game-Evolver is a dual-loop framework for end-to-end game making. A game orchestration agent (GOA) builds and tests the runnable artifact, while a harness proposal agent (HPA) learns which workflows, tools, and checks help it improve.

01 / Method

Two loops.
One runnable result.

The game artifact and the harness that builds it improve on different timescales.

INNER LOOP / GOA

Build, run, repair.

Edit the project, launch the real engine, inspect meaningful states, and repair what the player can see.

task→edit→run→replay
OUTER LOOP / HPA

Diagnose, propose, reuse.

Turn recurring failures into reusable harness elements, then test the next proposal against the current best.

traces→failures→library→harness
